# Media de la landing

Las rutas viven en `src/components/landing/media.ts` (campo `src`). Un `src` vacio muestra un recuadro punteado.

| Clave en media.ts | Archivo | Que muestra |
| --- | --- | --- |
| hero | crm-laptop.png | Inbox en laptop con conversacion y cotizacion |
| showcaseAi | ai-chat-solar.png | Respuesta de la IA con la cita "Catalogo 2026" |
| showcasePlaybook | sales-playbook.png | Playbook de ventas con etapas y objeciones |
| showcaseQuotes | quote-accepted.png | Presupuesto aceptado con pago verificado |
| demoVideo | demo.mp4 (pendiente) + automation-neon.png (portada) | Flujo WhatsApp, IA, presupuesto y pago |
| LOGOS[0..4] | logo-1.svg ... | Logos de clientes reales; si estan vacios, la seccion no se muestra |
| TESTIMONIALS[0..2] | testimonial-1.webp ... | Solo testimonios reales; sin texto, la seccion no se muestra |

Notas: material propio, sin stock externo. Los testimonios deben ser reales.
